# Steam Revenue Estimator

Веб-приложение для оценки выручки и дохода разработчика игры по количеству отзывов в Steam. Использует модель, близкую к VG Insights / Gamalytic (метод Boxleiter / review-to-sales ratio).

## Возможности

### Два режима работы

1. **По ссылке Steam** — пользователь вставляет ссылку на страницу игры (или App ID), приложение само определяет ID игры, через Steam API подтягивает название, цену, дату релиза, жанры и общее количество отзывов, после чего сразу выполняет расчёт.
2. **Вручную (офлайн)** — пользователь вводит данные сам. Часть полей можно пропустить — тогда используются значения по умолчанию или упрощённый расчёт. Работает без интернета (кроме загрузки данных по ссылке).

### Модель расчёта

```
владельцы ≈ отзывы × ratio
валовая выручка ≈ владельцы × цена × коэффициент_скидок
доход разработчика = валовая − все вычеты
```

Порядок вычетов:

1. Комиссия Steam (30%, с понижением до 25% после $10M и 20% после $50M — опционально)
2. Налог США у источника (withholding, 30% для РФ)
3. Доля издателя
4. Налог в стране разработчика
5. Комиссия за вывод/конвертацию валюты
6. Возвраты

Коэффициент `ratio` (продаж на 1 отзыв) подбирается автоматически по году релиза и цене, но его можно задать вручную в виде диапазона (мин / наиболее вероятный / максимальный).

### Налоговые режимы

- **Без налогов (по умолчанию)** — налог 0%.
- **Россия — физлицо (НДФЛ 13%)**
- **Россия — самозанятый (НПД 6%)**
- **Россия — ИП (УСН «Доходы» 6%)**
- **Россия — ИП (УСН «Доходы−расходы» 15%)**
- **Свой вариант** — ставка налога вводится вручную.

Для пресетов РФ автоматически учитывается налог США у источника (30% — договор США–РФ приостановлен с 2023 г.) и комиссия за вывод/конвертацию (2%).

### Результаты

Для каждого расчёта выводятся:

- **три сценария**: пессимистичный, наиболее вероятный и оптимистичный;
- **наиболее вероятная сумма** дохода разработчика;
- **разброс** возможных результатов (вместе с оценкой числа владельцев и валовой выручки);
- **формула**, по которой проводился расчёт;
- **пошаговый расчёт** с подставленными числами.

> Все цифры — оценка на основе публичных эвристик с погрешностью обычно ±50–100%. Точную выручку знает только разработчик/издатель.

## Технологии

- Backend: Node.js (без внешних зависимостей, стандартный модуль `http`) — раздаёт статику и проксирует запросы к Steam API.
- Frontend: чистый HTML/CSS/JS (без сборки и зависимостей).

Структура:

```
steam-revenue-estimator/
├── server.js          # HTTP-сервер + прокси к Steam API
├── package.json       # конфигурация для Render
├── index.html         # интерфейс
├── app.js             # модель расчёта и логика
├── style.css          # стили
├── README.md
└── .gitignore
```

## Запуск

Требуется Node.js 18+ (используется встроенный `fetch`).

```bash
node server.js
```

Затем откройте http://localhost:3001

Порт можно изменить через переменную окружения `PORT`.

## Развёртывание (GitHub Pages + Render)

Приложение состоит из двух частей:
1. **Статический frontend** (HTML/CSS/JS) — режим 2 (вручную) работает полностью автономно.
2. **Node-сервер** — нужен для режима 1 (загрузка данных Steam по ссылке), т.к. Steam API не разрешает CORS-запросы из браузера.

Для полноценной работы с режимом 1 нужно развернуть сервер.

### 1. Сервер на Render (бесплатный тир)

1. Создайте аккаунт на [render.com](https://render.com) и подключите GitHub-репозиторий.
2. Нажмите **New + → Web Service**, выберите репозиторий.
3. Настройки:
   - **Build Command**: `npm install` (оставьте по умолчанию)
   - **Start Command**: `npm start`
   - Render сам определит Node.js по наличию `package.json`.
4. Нажмите **Create Web Service** — Render присвоит URL вида `https://steam-revenue-estimator.onrender.com`.
5. Запомните этот URL.

### 2. GitHub Pages для frontend'а

1. Запушьте репозиторий на GitHub.
2. В настройках репозитория: **Settings → Pages**, выберите:
   - **Source**: Deploy from a branch
   - **Branch**: `master`, **folder**: `/ (root)`
   - Нажмите **Save**.
3. После деплоя GitHub даст URL вида `https://<user>.github.io/steam-revenue-estimator/`.
4. В файле `index.html` замените пустую строку на URL вашего Render-сервера:

```html
<script>window.STEAM_ESTIMATOR_API = 'https://steam-revenue-estimator.onrender.com';</script>
```

5. Запушьте изменение.

## API

- `GET /api/app?url=<ссылка>` или `GET /api/app?appid=<id>` — возвращает JSON с данными игры Steam:

```json
{
  "ok": true,
  "appid": "1049710",
  "name": "Minute of Islands",
  "type": "game",
  "isFree": false,
  "price": { "currency": "USD", "initial": 1999, "final": 199, "discountPercent": 90 },
  "releaseDate": "Jun 13, 2021",
  "genres": ["Adventure", "Indie"],
  "reviews": { "total": 1014, "positive": 783, "negative": 231, "score": 6, "scoreDesc": "Mostly Positive" }
}
```

## Ограничения

- По одному числу отзывов нельзя точно вычислить заработок — это оценочная модель.
- Коэффициент `ratio` зависит от года, цены, жанра, скидок, бандлов, Early Access и F2P-модели.
- Налоговые ставки и сборы упрощены (не учитываются фиксированные страховые взносы ИП, прогрессивный НДФЛ свыше 5 млн ₽/год и т.п.).
